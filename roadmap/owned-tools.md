Tools (so far the three paper maps behind the one map button) become something each player owns and keeps, instead of the same list everyone gets: made at the workbench or found, then in the bag's header for good, with no slot and no weight, never in a pile. Nothing new for players on its own: it is the groundwork the crackling radio, the locked places, the torn maps and the Far Woods all need, built once, first, so they do not each add the same thing and collide.

Why: every item that brings a tool would otherwise add the same saved list and the same migration.
