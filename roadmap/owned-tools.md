Tools (the paper map is the only one so far) become something each player owns and keeps: made at the workbench or found, then in the bag's header for good, with no slot and no weight, never in a pile. Today every player gets the same list and nothing is saved.

Why: the crackle radio, the tools that open locked places, the maps of farther regions and the Far Woods all need it. Built once, first, so those do not each add the same thing and collide.

More: [Movement and controls](../docs/DESIGN.md#movement-and-controls) (the paper map as a permanent tool).
