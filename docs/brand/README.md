# napoland brand

![napoland logo](preview.jpg)

The mark is a seal around the Old Stone. The stone is cracked and glowing, its hum spreads out in rings, and the firs stand around it: where Napoland began. The name is NAPOLAND in Archivo Expanded SemiBold, in capitals, spaced wide.

## Files

| File | Use it for |
|---|---|
| `mark.svg` | The seal alone, on dark backgrounds |
| `mark-ink.svg` | The seal alone, on light backgrounds |
| `app-icon.svg` | The seal on a rounded night square: favicons, app icons |
| `app-icon-square.svg` | The same, full bleed with more room: profile pictures (sites crop them round), maskable app icons |
| `logo-horizontal.svg` | The main logo, on dark backgrounds |
| `logo-horizontal-on-night.svg` | The same on its own night background, to drop anywhere |
| `logo-horizontal-ink.svg` | The main logo on light backgrounds |
| `logo-stacked*.svg` | The seal above the name, for square and tall spaces |
| `wordmark-bone.svg`, `wordmark-ink.svg` | The name alone, on dark or light |
| `wordmark-white.svg`, `wordmark-black.svg` | One color, for print, embroidery, stamps |

Every SVG has its letters as outlines, so none needs the font installed.

The game uses `apps/client/public/`: `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `site.webmanifest`, and `og.jpg` (the picture a shared link shows).

## Type

- **Archivo Expanded**, SemiBold (600, width 125), for the logo. Letters spaced 0.18 em.
- **Archivo**, Regular, for lines of text; SemiBold at width 112, in capitals spaced 0.2 em, for buttons and labels.

Archivo is under the SIL Open Font License. It is used only in the logo and in the ads: the game keeps Fredoka and Nunito.

## Please

- Keep space around the logo, at least half the seal's height.
- Use the bone logo on dark and the ink logo on light. On a busy picture, put a dark shade behind it.
- Do not recolor, stretch, rotate, outline or add shadows to it, and do not set the name in another font.
- The crack glows violet. Keep everything else in the logo bone or ink.
